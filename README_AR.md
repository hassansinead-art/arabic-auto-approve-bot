# بوت الموافقة التلقائية العربي لقنوات تيليغرام

## ماذا يفعل؟
- يوافق تلقائياً على طلبات الانضمام التي تصل إلى القناة التي تضبط معرّفها.
- لا يرسل رسائل خاصة، ولا رسائل ترحيب، ولا إعلانات.
- يسجل حالة الموافقة والأخطاء في سجل التشغيل فقط.

## المتطلبات
- حساب تيليغرام.
- بوت تنشئه عبر `@BotFather`.
- استضافة تدعم تشغيل Python باستمرار.
- إضافة البوت إلى القناة الخاصة كمشرف ومنحه صلاحية دعوة المستخدمين/إضافة المشتركين (Invite Users).

## 1) إنشاء البوت
1. افتح `https://t.me/BotFather`.
2. أرسل `/newbot`.
3. اختر اسماً للبوت ثم اسماً للمستخدم ينتهي بـ `bot`.
4. انسخ التوكن الذي يمنحك إياه BotFather، ولا تشاركه مع أي شخص.

## 2) إعداد القناة الخاصة
1. افتح إعدادات القناة > المشرفون > إضافة مشرف.
2. أضف البوت الذي أنشأته.
3. فعّل صلاحية دعوة المستخدمين/إضافة المشتركين.
4. تأكد أن رابط الدعوة المستخدم يفعّل **طلب الانضمام**؛ البوت لا يستطيع الموافقة على روابط دعوة عادية لا تتطلب طلباً.

## 3) معرفة معرّف القناة
معرّف القناة الخاصة عادةً يكون رقماً سالباً يبدأ بـ `-100`.
يمكنك استخراج معرّف القناة باستخدام أداة موثوقة لمعرفة معرّفات المحادثات، أو من سجل تحديث `chat_join_request` بعد وصول طلب تجريبي. لا تضع رابط الدعوة مكان المعرّف.
إذا استخدمت طريقة استخراج عبر بوت خارجي، لا تعطِه توكن البوت الخاص بك.

## 4) رفع الملفات إلى الاستضافة
ارفع `bot.py` و`requirements.txt` إلى مشروع Python على استضافة تدعم عملية تعمل باستمرار.
اضبط متغيرات البيئة التالية من لوحة الاستضافة:
- `BOT_TOKEN`: التوكن الذي حصلت عليه من BotFather.
- `CHANNEL_ID`: معرّف قناتك الخاصة، مثل `-1001234567890`.

أمر التثبيت:
```bash
pip install -r requirements.txt
```

أمر التشغيل:
```bash
python bot.py
```

إذا كانت الاستضافة تطلب أمر بدء التشغيل، ضع:
```bash
python bot.py
```

## 5) الاختبار
1. تأكد أن البوت مشرف وله صلاحية دعوة المستخدمين.
2. اطلب من حساب آخر الانضمام باستخدام رابط يتطلب موافقة.
3. ينبغي أن تتم الموافقة تلقائياً.
4. تحقق من أن سجل الاستضافة يعرض نجاح الموافقة، وأن العضو لم تصله رسالة خاصة من البوت.

## ملاحظات مهمة
- هذا المشروع لا يحتوي على أي استدعاء لإرسال رسائل خاصة؛ يستخدم فقط `approve_chat_join_request`.
- يجب تشغيله على استضافة لا توقف العملية باستمرار. بعض الخطط المجانية تنام أو توقف الخدمات، وقد يتوقف البوت حينها.
- لا ترفع ملف التوكن إلى مستودع عام، ولا ترسل التوكن لأي شخص.
- لا يمكن ضمان التشغيل الدائم إلا بحسب سياسة وتوفر الاستضافة التي تختارها.
